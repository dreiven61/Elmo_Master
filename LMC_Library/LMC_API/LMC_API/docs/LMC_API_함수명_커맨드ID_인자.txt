LASAL Motion Control Lib 함수명 / Command ID / 인자 정리
작성 기준: LMC_API_Delivery PC source, 2026-07-10

중요
- API는 물리 단위를 변환하지 않는다. 호출자가 physical value * LMC_Units를 계산해 DINT int로 전달한다.
- PC request builder/public path는 캡처 대상 23/23이다. 실제 PLC E2E 검증은 0/23이다.
- 0x2051과 0x20E7은 PC serializer/parser까지 구현됐지만 현재 LASAL은 -5를 반환한다.
- callback은 UDP raw byte[] event만 제공한다. typed callback payload는 미정이다.
- async 메소드는 같은 frame/parser를 사용하며 CancellationToken을 받는다.

구분	Public API	Command ID	인자	반환값 / 비고
연결	RpcInitConnection	0x8080, 0x405C	remoteAddress, remotePort, localAddress[, callbackPort, eventMask]	Session init 뒤 UDP callback 등록
연결	RpcInitConnectionAsync	0x8080, 0x405C	동일 + CancellationToken	취소 가능한 비동기 연결
연결	CloseConnection	0x405D	없음	close ACK 오류를 호출자에게 전달하고 transport를 정리
연결	CloseConnectionAsync	0x405D	CancellationToken	취소 가능한 비동기 종료
연결	LMCConnection(options)	해당 없음	LMCConnectionOptions	connect/read/send/callback join timeout, callback source 검증
연결	ConnectionStateChanged	해당 없음	event	Disconnected/Connecting/Connected/Closing/Faulted
연결	LastInitializationException / LastTransportException / LastCloseException	해당 없음	property	초기화 protocol, transport, close 오류를 분리 보존

연결	CallbackListenerError	해당 없음	event	callback listener 오류

연결 lifecycle 주의
- timeout/전송 오류와 in-flight 취소는 해당 transport를 폐기하고 Faulted로 전환한다.
- queue 대기 중 취소는 현재 active request의 socket을 닫지 않는다.
- invalid reconnect 인자는 기존 session을 유지하며, reconnect 성공 뒤 이전 axis/group object는 stale handle로 거부된다.
- close nonzero ACK는 local cleanup 뒤 예외로 전달되고 RpcCloseResponse/LastCloseException에 보존된다.

권장 초기 실기 흐름
RpcInitConnection → axis/group 이름 lookup → ReadStatus/ReadPosition/GetMembers/GroupReadStatus → 한 축씩 PowerOn → 저속 MoveRelativeEx → Stop → PowerOff

현재 장비 검증 제한
- 0x2049, 0x2085, 0x2051, 0x20A4, 0x20E7은 현재 LASAL에서 unsupported -5다.
- CyWork-only source와 LASAL IDE build는 완료했지만 PLC download/실제 packet 재캡처 전에는 production motion 완료로 판정하지 않는다.
- multi-PC ownership은 PC DLL이 아니라 LASAL session/dispatcher에서 강제해야 한다.
