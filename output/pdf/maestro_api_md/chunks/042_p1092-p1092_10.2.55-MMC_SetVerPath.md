10.2.52 MMC_GetVerPath
Description Reads the Maestro firmware flash version path from the Maestro itself.
This is set during a TFT firmware download from the host server.
When it becomes necessary to use this function block, please contact Elmo
for further information.
10.2.53 MMC_DownloadVersion
Description Performs a download of new firmware version to the Maestro. When it
becomes necessary to use this function block, please contact Elmo for
further information.
10.2.54 MMC_ReadDownloadVersionStatus
Description Returns the status of the last downloaded version.
When it becomes necessary to use this function block, please contact
Elmo for further information.
10.2.55 MMC_SetVerPath
Description As part of the download firmware functions, sets the Maestro firmware
flash version path from the Maestro itself. This is set during a TFT
firmware download from the host server.
When it becomes necessary to use this function block, please contact
Elmo for further information.
