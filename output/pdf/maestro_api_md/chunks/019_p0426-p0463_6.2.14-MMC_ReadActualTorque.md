###### 6.2.14 MMC_ReadActualTorque
6.2.14 MMC_ReadActualTorque
Returns the actual torque value or force for a controlled axis, as long as Enable is set.
MMC_LIB_API int MMC_ReadActualTorqueCmd(
IN MMC_CONNECT_HNDL hConn,
IN MMC_AXIS_REF_HNDL hAxisRef,
IN MMC_READACTUALTORQUE_IN* pInParam,
OUT MMC_READACTUALTORQUE_OUT* pOutParam
);
Motion Mode NC - Supported Distributed - Supported
Source GMAS\includes\MMC_PLCopen_single_API.h
GMAS Programming(IEC 61331 Program)\ElmoSingleAxis
Parameters
hConn
[IN] Connection handle input using hConn, where MMC_CONNECT_HNDL is the
Connection Handle Type. It should be noted that this connection handle is common
throughout all Maestro functions. This connection handle is returned by the the Init
Connection command. If an error occurs, the function returns -1 and a MMC_LIB_API
error with more details.
hAxisRef
The axis/group reference handle type returned by the the GetAxisRef command.
pInParam
Points to the MMC_READACTUALTORQUE input data structure using the
MMC_ReadActualTorque function.
pOutParam
Points to the MMC_READACTUALTORQUE_OUT output structure receiving information
as a result of calling the MMC_ReadActualTorque function.
Remarks
For CAN only, depending on the mode, the position may not be updated. The torque is mapped and not the
position when in all opModes, not just in interpolated mode.
If Distributed motion mode is in operation, then this will depend whether the parameter was mapped v ia
PDO mapping. Refer to the PDO3, 4 configuration mapping functions in the PDO Mapping section.
For EtherCAT, the actual position must be part of the Input Group configured.
Scope
The usStatus mode Done is TRUE when the data-output Torque is valid. If Enable is Reset, the data loses its
validity, and Done is also reset, even if new data is available.
The output dActualTorque is a signed value.
