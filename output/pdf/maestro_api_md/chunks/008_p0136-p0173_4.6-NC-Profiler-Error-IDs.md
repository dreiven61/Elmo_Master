- 1045 Profiler Error: Two points
are very close
This error originates from the MoveCircular function in Border
mode.
In this mode three points are defined:
* Start point SP
* Border point BP
* End point EP
Prior to running the function block, check that each set of these
points are not too close to each other (SP vs. BP, SP vs. EP, BP
vs. EP).
If all of the points are close together, an error will be created.
The logic of close proximity checking:
If( (ABS(Point[1].x - Point[2].x) <1e-7) &&
(ABS(Point[2].y - Point[3].y) <1e-7) &&
(ABS(Point[1].z - Point[3].z) <1e-7) )
Then, the points are very close (not permitted)
Else, the points are OK (permitted)

on the same straight line (two points define the line).
