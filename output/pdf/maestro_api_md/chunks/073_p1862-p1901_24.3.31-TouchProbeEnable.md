Touch Probe mechanism associated with an axis upon activation (one or two Touch
Probe mechanisms can be associated with the same axis).
The captured positions for each Touch Probe mechanism is stored in a dedicated cyclic
array in the Shared Memory section, as binary data (not UU). The total size in shared
memory reserved for all 6 cyclic arrays is 100,000 pts, with a simple journal instruction:
"Mechanism B cannot be used unless A has been allocated," etc.
The cyclic arrays also serves for Input Capture data from the Maestro. The captured
positions are copied to the user space memory,via the dedicated function call:
GetTouchProbeData(), with a maximum of 350 points per function call. Each function
call lowers the number of points in the array by the number of points read. When the
number of points in the array (captured positions that haven't been read) exceeds
100,000, the newer captures will override the previous captured values.
Values of usShmArraySizeAlloc are therefore 1 - 100 (given in thousands).
Array size allocation (values: 2-100000)
usConfig
usConfig controls and determines the latched event (or events, when 2 Touch Probe
mechanisms are associated with the same drive):

- Triggers on Rising and/or Falling edge of Source signal

Source GMAS\includes\CPP\MMCSingleAxis.h
.NET Definition
Parameters
cCmd[3]
Name of the parameter limited to three characters. Any positive character value with a
maximum of 2 bytes

Integer value of the data that is to be set.
Optionally, float value of the data.
throw (CMMCException)

Function Name Structure name
The axis reference Error ID
Status of the axis.
Scope
