###### 6.2.40 MMC_GetProfileConditioning
6.2.40 MMC_GetProfileConditioning
This method obtains the Profile Conditioning mode of operation data for axes on which this mode of
operation is enabled.
MMC_LIB_API int MMC_GetProfileConditioning(
IN MMC_CONNECT_HNDL hConn,
IN MMC_AXIS_REF_HNDL hAxisRef,
IN MMC_PROFCONDINF_IN* i_params,
OUT MMC_PROFCONDINF_OUT* o_params
);
Motion Mode NC - Supported Distributed - Supported
Source GMAS\includes\MMC_drive_comm_API.h
GMAS Programming(IEC 61331 Program)\ElmoSingleAxis
Parameters
hConn
[IN] Connection handle input using hConn, where MMC_CONNECT_HNDL is the
Connection Handle Type. It should be noted that this connection handle is common
throughout all Maestro functions. This connection handle is returned by the Init
Connection command. If an error occurs, the function returns -1 and a MMC_LIB_API
error with more details.
hAxisRef
Axis/group reference handle type returned by the GetAxisRef command
i_params
Points to the MMC_PROFILECOND input data structure using the
MMC_GetProfileConditioning function.
o_params
Points to the MMC_PROFILECOND_OUT output structure receiving information as a
result of calling the MMC_GetProfileConditioning function.
Remarks

Scope
This function is only used for Single Axis and for a specific axis under the condition that the axis is disabled.
