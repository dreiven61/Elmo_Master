###### 7.10.16 MMC_TrackRotaryTable
7.10.16 MMC_TrackRotaryTable
The MMC_TrackRotaryTable function executes a smooth RAMP-IN motion from any robot position (in MCS),
on to the Part located on a moving Rotatory Table (in PCS). As soon as the robot reache s the target point on
the Rotatory Table it moves synchronously with the Rotatory Table (in PCS), that is to say, it tracks the
Rotatory Table while performing motion in PCS.
MMC_LIB_API int MMC_TrackRotaryTable(
IN MMC_CONNECT_HNDL hConn,
IN MMC_AXIS_REF_HNDL hAxisRef,
IN MMC_TRACKROTARY_IN* pInParam,
OUT MMC_TRACKROTARY_OUT* pOutParam
);

An array of 6 parameters, (x,y,z,u,v,w), defining the Static 6DoF (6 degrees of freedom)

7.10.17 MMC_TrackSyncOut
The MMC_TrackSyncOut function executes a smooth RAMP Out motion from a synchronized PCS motion to
an MCS target position until halted.
MMC_LIB_API int MMC_TrackSyncOut(
IN MMC_CONNECT_HNDL hConn,
IN MMC_AXIS_REF_HNDL hAxisRef,
IN MMC_TRACKSYNCOUT_IN* pi_params,
OUT MMC_TRACKSYNCOUT_OUT* po_params
);
Source GMAS\includes\MMC_PLCopen_group_API.h
Parameters
hConn
[IN] Connection handle input using hConn, where MMC_CONNECT_HNDL is the Connection
Handle Type. It should be noted that this connection handle is common throughout all
Maestro functions. This connection handle is returned by the Init Connection command.
hAxisRef
Vector reference handle type returned by the AxisRef command. This is the group executing
the Ramp and Track. It is defined as the "Slave" in the Track mode.
pi_params
Points to the MMC_TRACKSYNCOUT input data structure using the MMC_TrackSyncOut
function.
po_params
Points to set the kinematic transformation MMC_TRACKSYNCOUT_OUT output structure
receiving information, as a result of calling the MMC_TrackSyncOut function.
Remarks
MMC_TrackSyncOut supports two modes of operation; Immediate and None -immediate:
Immediate states:
- Disengagement from master (Rotary/Conveyor Belt) in terms of PCS conversions. Profiler still reflecting
the master position (and speed) while in MCS motion.
- Performs a synchronized motion in MCS until the Z axis reaches the safe zone then slowing down until
halted.
Non-Immediate states:
- Disengagement from master (Rotary/Conveyor Belt) in terms of PCS conversions. Profiler still reflecting
the master position (and speed) while in MCS motion.
- Performs a synchronized motion in MCS until the Z axis reaches the safe zone. Then proceeds with MCS
motion to target positions until halted or aborted.
The function uses the standard queue for motion commands. During the Sync Phase, while sync out is

synchronized, after which it decelerates until halted then moves to Standby. Refer to the sections Trackin g
