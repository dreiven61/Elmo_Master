8.10.7 MMC_GetTableIndex
This function obtains the PVT index.
MMC_LIB_API int MMC_GetTableIndexCmd(
MMC_CONNECT_HNDL hConn,
MMC_GETTABLEINDEX_IN* pInParam,
MMC_GETTABLEINDEX_OUT* pOutParam
);
Motion Mode NC - Supported Distributed - Not supported
Source GMAS\includes\MMC_general_API.h
GMAS\includes\MMC_PVT_ECAM_API.h
GMAS Programming(IEC 61331 Program)\ElmoGenAxis
Parameters
hConn
[IN] Connection handle input using hConn, where MMC_CONNECT_HNDL is the
Connection Handle Type. It should be noted that this connection handle is common
throughout all Maestro functions. This connection handle is returned by the Init
Connection command. If an error occurs, the function returns -1 and a MMC_LIB_API
error with more details.
hAxisRef
Axis/group reference handle type returned by the GetAxisRef command.
pInParam
Points to the MMC_GETTABLEINDEX input data structure using the
MMC_GetTableIndexCmd.
pOutParam
Points to the MMC_GETTABLEINDEX_OUT output structure receiving information, as a
result of calling the MMC_GetTableIndexCmd.
Remarks
When applying to a single-axis PVT, the multi-axes values of the parameter MMC_MOVETABLE_OUT are not
relevant, and therefore any value can be provided.
Scope
All
