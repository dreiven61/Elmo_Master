Remarks
A kinematic transformation is a representation of the machine construction. The input
MMC_SETKINTRANSFORM_IN refers to a kinematic model including the parameters.
This function block always behaves on a pre-defined AxesGroup. Since a kinematic transformation always
has to fit to an appropriate AxesGroup, a call to some group function block in MCS mode will lead to an error
unless an appropriate Kinematic is defined. For a further detailed explanation, refer to the section
7.1Coordinate System and kinematic transformation.
Scope
The SetKinTransform function can only be called in the following states:

Parameters
ucExecute
Start the execution command at the rising edge. Boolean TRUE/FALSE values.
ulTrCoef
The parameter ulTrCoef is defined by the type of supported MCS transform function
according to the definition of the array of [NC_TR_FUNC_ID_ENUM] enumerators
defined by the linear transformation iMcsToAcsFuncID. The value of ulTrCoef is 8 bytes
(double) and ranges between any +/-15 digit value.
These coefficients depend on the transition function type. Presently, Elmo supports
only two functions defined by the following enumerator NC_TR_FUNC_ID_ENUM:
NC_TR_NONE_FUNC = 0
NC_TR_SHIFT_FUNC = 1
NC_TR_LAST_ FUNC = 2
Each of the above enumerations has a different connotation dependant on the
transition function type. The coefficients are a two dimensional double array 16 x 3,
with the following definitions:
16 - the maximum number of axes
3 - the three inputs for each axis
An important point when entering the coefficients:
In order to avoid problematic position adjustments (when using MCS mode) always
maintain the following ratio between the coefficients:
NC_BACK_TR_RATIO_COEF x NC_FRWD_TR_RATIO_COEF =1
[NC_MAX_NUM_COEF] is defined as 3.
For further details refer to the section 7.4PCS - Product Coordinate System.
